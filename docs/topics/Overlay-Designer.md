# Overlay Designer

<web-summary>Use the built-in WYSIWYG Overlay Designer to create and customize your own poster icon styles visually, without coding.</web-summary>
<show-structure for="chapter,procedure" depth="2"/>

The Overlay Designer is a built-in visual editor introduced in FoliCon v5.3.0. It lets you create your own custom poster icon overlay styles directly inside FoliCon, without writing any code.

<img src="overlay-designer.png" border-effect="rounded" alt="Overlay Designer window"/>

## Features

With the Overlay Designer, you can:
* **Design visually**: Use a drag-and-drop / WYSIWYG interface to build your overlay.
* **Adjust layout**: Change the positioning and layout of elements like the rating badge, title text, and overlay shape.
* **Configure text styling**: Customize the font, size, colour, and weight of your text.
* **Real-time live preview**: See exactly how the overlay looks on an actual folder icon in real-time as you design.
* **Save as a custom style**: Save your finished overlay as a reusable custom style.
* **Easy access**: Your saved custom overlays automatically appear in the overlay picker alongside built-in options and those from the [Overlay Store](Overlay-Store.md).

## Typical Design Workflow

<procedure title="How to design a custom overlay" id="design-workflow">
    <step>Open <strong>Poster Icon Config</strong> and launch the <strong>Overlay Designer</strong>.</step>
    <step>Start from a blank canvas or duplicate an existing overlay to use as a starting point.</step>
    <step>Adjust the elements on the canvas — move, resize, and style them to your liking.</step>
    <step>
        <p>Watch the live preview panel update in real time to ensure your design looks perfect.</p>
        <img src="overlay-designer-preview.png" border-effect="rounded" alt="Live preview panel"/>
    </step>
    <step>Give your new overlay a descriptive name.</step>
    <step>Save your design. It immediately appears in the overlay list ready to be used.</step>
</procedure>

## Sharing Your Overlay

Once you're happy with your design, you can export it as an overlay package and share it with the community via the FoliCon-Overlays repository. See [Creating an Overlay](Creating-an-Overlay.md) for a full guide on exporting and sharing.

<note>
<strong>Example:</strong> FoliCon v5.3.0 ships with a Doraemon-themed example overlay built entirely with the designer — check it out in the Overlay Store or in the built-in overlays list!
</note>
