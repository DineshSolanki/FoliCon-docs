# Poster Mode

<web-summary>Create folder icons using media posters, artwork, and built-in overlays.</web-summary>
<show-structure for="chapter,procedure" depth="2"/>

Poster mode is for people who want to change their folder icons to feature the poster or artwork of a specific movie, TV show, or game, combined with FoliCon's built-in icon overlays.

## Search and Selection

Poster mode offers four search modes to find exactly what you're looking for:
<img src="search-mode.png" border-effect="rounded" alt="Search modes"/>

<note>Professional mode can search for any type of media.</note>

<tip>FoliCon supports the Plex standard naming format, such as <code>TITLE (YEAR) {tmdb/imdb/tvdb-id}</code>.</tip>

When you search for media, FoliCon shows details such as the title, year, rating, plot, and trailer.
<img src="search-result.png" border-effect="none" alt="Search result"/>

It also remembers the selected title when choosing from ambiguous results, auto-selecting the title on your next search in case of a failure.
<tip>This media info can be cleared by using the <strong>Delete media info</strong> option.</tip>

## Custom Overlays

You can apply custom icon overlays to your poster icons. Currently, there are six built-in overlays available:
<img src="icon-overlays.png" border-effect="none" alt="Icon overlays"/>

- **Legacy** — The original FoliCon overlay.
- **Alternate** — An alternative to the Legacy overlay.
- **Faelpessoal** — The default overlay since v3.7, which includes the media title. Named after designer [faelpessoal](https://www.deviantart.com/faelpessoal).
- **Liaher** — A minimalistic look, named after designer [Liaher](https://www.deviantart.com/liaher).
- **Faelpessoal Horizontal** — Best suited for landscape or game artwork.
- **Windows 11 Style** — A sleek Windows 11-style overlay, best for horizontal posters.
  <img src="win11-overlay.png" border-effect="rounded" alt="Windows 11 style overlay"/>

### Overlay Store and Designer

You are not limited to the built-in overlays! 
- **Overlay Store**: Browse and install community-created overlays from <ui-path>Poster Icon Config | Browse Overlay Store…</ui-path>. For more details, see <a href="Overlay-Store.md">Overlay Store</a>.
- **Overlay Designer**: Create your own custom overlays. Learn more in the <a href="Overlay-Designer.md">Overlay Designer</a> guide.

## Media Details and Previews

### Image Previews
You can choose from a large variety of available posters for your media.
<img src="more-posters.png" border-effect="none" alt="More posters"/>

<note>Single click on any poster thumbnail to see a full-size preview. Double click to select the image.</note>

The preview window correctly renders **transparency** for PNG images, allowing you to see exactly how your icon will look.
<img src="full-preview.png" border-effect="none" alt="Full preview"/>

### Ratings
Poster mode includes a feature to add media ratings directly to your folder icons, giving you a quick visual indicator of the media's score.

### Videos and Trailers
Poster mode shows available trailers and videos for the selected media. All media types (Movies, TV shows, and Games) now support multiple videos. Click the video thumbnail to watch it directly in FoliCon's built-in viewer.
