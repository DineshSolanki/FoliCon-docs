# Usage

<web-summary>Learn how to use FoliCon to load folders and generate custom icons.</web-summary>

<note>First time using FoliCon? Make sure to check out the <a href="Getting-Started.md">Getting Started</a> guide to complete the initial setup wizard before proceeding.</note>

Using FoliCon is straightforward.

> Download the latest version from [here](https://github.com/DineshSolanki/FoliCon/releases/latest)
{style="note"}

<procedure title="Loading Folders" id="loading-folders">
  <step>Click on the <control>Load</control> button to load a parent folder.</step>
  <step>This folder should contain all the subfolders that you want to create icons for.</step>
  <step>You should now see the path of the folder in the top center (just below the menu bar).</step>
</procedure>

<tip>Double-clicking the path will open that folder.</tip>

Select your search mode: [Poster](Poster-Mode.md) or [Professional](Professional-Mode.md).

<tabs>
  <tab title="Poster Mode">
    <procedure title="Using Poster Mode" id="using-poster-mode">
      <step>Select the type of media you want to search for.</step>
      <step>Click on the <control>Make Icons</control> button to start the process.</step>
      <step>
        You will see a list of found searches in the left panel of a new window, and the description of the media on the right side.
        <tip>Move the slider above the description to adjust the font size.</tip>
        <note>There is a search box just below the list, where you can search as you want.</note>
      </step>
      <step>Here you can also set a custom rating for this media, and see the available trailers and videos for this media.</step>
      <step>Double-click on the preview poster or click on <control>show more</control> to see more posters for this media.</step>
      <step>Once you are satisfied with the poster, click on <control>Pick Selected</control> or double-click on the media name to select.</step>
    </procedure>
  </tab>

  <tab title="Professional Mode">
    <procedure title="Using Professional Mode" id="using-prof-mode">
      <step>Click on the <control>Make Icons</control> button to start the process.</step>
      <step>You will see various folder icons in this window.</step>
      <step>Click to select or double-click to see a full preview of the icon.</step>
    </procedure>
  </tab>
</tabs>

<procedure title="Finishing Up" id="finishing-up">
  <step>Click on <control>Skip</control> to skip this media. Or click on <control>ALL</control> to skip this and all remaining media.</step>
  <step>Follow the same process for all the media.</step>
  <step>You will be back to the main window once you are done with all the media.</step>
  <step>You will see a progress bar as the icons are being created.</step>
</procedure>
