# Usage

Using FoliCon is straightforward.

> Download the latest version from [here](https://github.com/DineshSolanki/FoliCon/releases/latest)
{style="note"}

<list>
  <li>Click on the 'Load' button to load a parent folder.</li>
  <li>This folder should contain all the subfolders that you want to create icons for.</li>
  <li>You should now see the path of the folder in the top center (just below the menu bar).</li>
</list>

<tip>Double-clicking will open that folder.</tip>

Select your search mode [Poster](Poster-Mode.md) or [Professional](Professional-Mode.md).

<tabs>
  <tab title="Poster Mode">
    <list>
      <li>Select the type of media you want to search for.</li>
      <li>Click on the 'Make Icons' button to start the process.</li>
      <li>
        You will see a list of found searches in the left panel of a new window, and the description of the media on the right side.
        <tip>Move the slider above the description to adjust the font size.</tip>
        <note>There is a search box just below the list, where you can search as you want.</note>
      </li>
      <li>Here you can also set a custom rating for this media, and see the available trailer/associated video for this media.</li>
      <li>Double-click on the preview poster or click on 'show more' to see more posters for this media.</li>
      <li>Once you're satisfied with the poster, click on 'Pick Selected' or double-click on the media name to select.</li>
    </list>
  </tab>

  <tab title="Professional Mode">
    <list>
      <li>Click on the 'Make Icons' button to start the process.</li>
      <li>You will see various folder icons in this window.</li>
      <li>Click to select or double-click to see a full preview of the icon.</li>
    </list>
  </tab>
</tabs>

<list>
  <li>Click on 'Skip' to skip this media. Or click on 'ALL' to skip this and all remaining media.</li>
  <li>Follow the same process for all the media.</li>
  <li>You'll be back to the main window once you're done with all the media.</li>
  <li>You will see a progress bar as the icons are being created.</li>
</list>
