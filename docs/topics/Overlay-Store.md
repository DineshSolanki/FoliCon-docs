# Overlay Store

<web-summary>Discover and install community-created custom icon overlay styles for your folders in the Overlay Store.</web-summary>
<show-structure for="chapter,procedure" depth="2"/>

Introduced in FoliCon v5.3.0, the Overlay Store is a built-in community catalog where you can discover, preview, and install custom icon overlay styles created by the community.

<img src="overlay-store.png" border-effect="rounded" alt="Overlay Store window"/>

## Opening the Overlay Store

To open the Overlay Store, navigate to:
<ui-path>Poster Icon Config | Browse Overlay Store…</ui-path>

## Features

In the Overlay Store, you can:
* **Browse** all available overlays from the community catalog.
* **Search** by name, author, description, or tags.
* **Filter** overlays by category.
* **Preview** an overlay before installing it to see exactly how it would look on a folder icon.
* **Install** an overlay with one click.
* **Update** an overlay when a new version is available.
* **Remove** installed overlays.
* **Track** download and installation progress per overlay.

<img src="overlay-store-search.png" border-effect="rounded" alt="Searching in the Overlay Store"/>

## Managing Overlays

<procedure title="How to install an overlay" id="install-overlay">
    <step>Open the Overlay Store by clicking <ui-path>Browse Overlay Store…</ui-path> in the Poster Icon Config window.</step>
    <step>Browse or search for an overlay you like.</step>
    <step>Select an overlay to see its details and preview it.</step>
    <step>Click the <control>Install</control> button.</step>
</procedure>

<img src="overlay-store-preview.png" border-effect="rounded" alt="Preview panel"/>

<note>
Installed overlays are stored in your user profile folder. Once installed, they appear in the overlay picker alongside the built-in styles (Legacy, Alternate, Faelpessoal, Liaher, Faelpessoal Horizontal, Win11), and you can apply them immediately.
</note>

<tip>
You can have as many overlays installed as you like. Installed overlays update independently of the app, so you can always stay up-to-date with your favorite styles. Be sure to preview overlays before installing to find the style that perfectly matches your taste!
</tip>

## About the Community Catalog

The overlay catalog is powered by the public [FoliCon-Overlays](https://github.com/DineshSolanki/FoliCon-Overlays) repository on GitHub. Community members can submit their own overlays there to share with everyone. Overlays are data-driven packages, which means they do not require a FoliCon update to be distributed or updated.

<tip>
Interested in making your own? To create your own overlay and share it, see the Overlay Designer and Creating an Overlay pages.
</tip>
