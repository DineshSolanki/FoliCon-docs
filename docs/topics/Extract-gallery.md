# Extract Gallery

<web-summary>Learn how to use FoliCon's Extract Gallery feature to browse and select images from DeviantArt archive uploads in Professional Mode.</web-summary>

FoliCon serves Professional Mode data from DeviantArt, where creators can upload a single image or sometimes an archive (such as `.zip` or `.rar`) of images.
FoliCon can extract those archives and let you choose from the images inside.

Right-click on any image in the Professional Mode search results and click <control>Extract Gallery</control> to extract the images from the archive.

The extracted images will be shown in a new window where you can select or preview the image you want to set as the folder icon.

<warning>

**DeviantArt weekly download limits:** DeviantArt introduced download limits that reset weekly. If you have reached your limit, Extract Gallery will show an error message. This is a DeviantArt-side restriction — wait for the limit to reset or try again later.

</warning>
